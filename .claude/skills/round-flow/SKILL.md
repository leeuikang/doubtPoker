# DoubtPoker 라운드 흐름 참조

## 라운드 시작

1. 선 플레이어: 첫 게임 랜덤, 이후 전 판 승자
2. 각 플레이어 7장 배분, 나머지는 스톡
3. 스톡 상단 1장을 버림 더미에 세팅
4. **땡큐 타이머 10초** 시작 → 선언자가 먼저 멜드 실행, 없으면 딜러부터 시계방향 진행

## 턴 구조 (TurnPhase)

```
DRAW → ACTION → DISCARD
```

| 단계 | 내용 | 제한 |
|------|------|------|
| DRAW | 스톡 또는 버림 더미 상단 1장 | 필수 |
| ACTION | 멜드·확장·스탑·지목·자진공개 | 선택, 복수 가능 |
| DISCARD | 손패 1장 버림 더미로 | 필수, 버린 후 땡큐 타이머 5초 |

**전체 턴 제한: 20초** (초과 시 자동 드로우 + 7 제외 최고 점수 카드 버림)

## 땡큐 규칙

- 버림 더미에 카드 버려지면 **즉시 5초** (게임 시작 시 **10초**)
- 누구나 선언 가능, 먼저 선언한 자 우선
- 동시 선언: 버린 플레이어 기준 시계방향 가장 가까운 순
- 땡큐 성공: 버린 카드 가져와 멜드 실행, 원래 턴 순서 건너뜀

## 멜드 규칙

| 종류 | 조건 | 확장 |
|------|------|------|
| SET | 같은 숫자 3장 이상 | 최대 4장 |
| STRAIGHT | 같은 무늬 연속 3장 이상 | 양쪽 무제한 |
| SOLO_SEVEN | 7 단독 | 없음 |

- 확장 조건: 해당 턴에 직접 멜드를 1건 이상 완성한 플레이어만 가능
- 한 카드는 복수 멜드에 동시 소속 불가

## 거짓말 멜드

- 멜드당 최대 **1장** 허위 카드 포함 가능
- SET: 실제 2장 공개 + 1장 숫자 속임
- STRAIGHT: 숫자·무늬 모두 속임, 선언 정확히 일치해야 함
- 거짓말 이후 **손패 1장 이상** 유지 필수 (고잉아웃 불가)

## 지목 (Doubt)

- **자신의 턴**에 **직전 멜드**만 지목 가능
- 성공: 멜드 소유자가 해당 멜드 + 붙인 카드 전부 가져감 + 1장 드로우
- 실패: 지목자가 1장 드로우
- 자진 공개: 자신의 턴, 본인이 낸 거짓말 멜드 공개 가능 → 확장한 플레이어들 각 1장 드로우

## 종료 조건 (RoundEndCondition)

| 조건 | 트리거 | 승자 |
|------|--------|------|
| GOING_OUT | 모든 카드 멜드 or 마지막 1장 버림 | 해당 플레이어 |
| STOP | 턴 시작 시 핸드 ≤ 10점 선언 | 전체 핸드 공개 후 최저점 |
| STOCK_DEPLETED | 스톡 3번째 소진 | 최저점 보유자 |
| BANKRUPTCY | 핸드 10장 이상 순간 즉시 탈락 | 나머지 플레이어 |

스톡 재구성: 버림 더미 맨 위 제외 나머지 섞어 재사용, **최대 2회**

## 점수 배율 (합산 적용)

| 항목 | 배율 | 적용 대상 |
|------|------|-----------|
| 훌라 (멜드 없이 고잉아웃) | ×4 | 승리 점수 |
| 스탑 선언 후 패배 | ×2 | 본인 점수 |
| 핸드에 7 보유 | ×2 | 본인 점수 |
| 파산 | max(본인×2, 타 패배자 최고점) | 본인 점수 |

## 카드 점수

| 카드 | 점수 |
|------|------|
| A | 1 |
| 2~6, 8~10 | 표시 숫자 |
| 7 | **14** (핸드에 남을 때만) |
| J | 11 |
| Q | 12 |
| K | 13 |

## 토너먼트

- 시작 점수: **100점** (4인 기준)
- 점수 0 이하 → 즉시 탈락, 이후 라운드 불참
- 총 **10라운드**, 최고 점수 우승
- 공동 승자: 합산 점수 동등 분배

## AI 대체 규칙 (연결 끊김)

- 땡큐 선언 안 함
- 거짓말 지목 안 함
- 스탑 선언 안 함
- 매 턴: 드로우 후 **7 제외** 최고 점수 카드 버림
